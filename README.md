# Dealer Mobil Application

A C++ application for managing car manufacturers and vehicle products using Multi Linked List.

## Description

This project is a dealer management application developed to help dealer staff manage manufacturer and vehicle product data.

## Features

- Add, edit, and delete manufacturer data
- Add, edit, and delete vehicle product data
- Search manufacturer and vehicle product data
- Manage relationships between manufacturers and vehicle products
- Manage production data
- Display manufacturers and products with the highest sales

## Data Structure

This application uses a **Multi Linked List (M to N)** structure consisting of:

- **Parent List:** Circular Doubly Linked List
- **Child List:** Circular Doubly Linked List
- **Relation List:** Singly Linked List

## Technologies

- C++
- Multi Linked List
- Structured Programming
